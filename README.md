# ⚡ CADe_SIMU & Classic Control Projects
مرحباً بك في البورتفوليو الخاص بتطبيقات التحكم الكلاسيكي! 
هذا الفهرس يجمع جميع الدوائر والتجارب العملية التي قمت بتصميمها ومحاكاتها باستخدام برنامج CADe_SIMU وتنفيذها عملياً.

### 🗂️ قائمة المشاريع (اضغط على اسم المشروع لفتحه):

1. **[Washing Machine Classic Control](https://github.com/youssf123654/Washing-Machine-Classic-Control)**
   * تصميم دائرة تحكم لغسالة (حركة يمين/يسار متواصلة) باستخدام التايمرات والأسلاك العملية.

2. **[Continuous Motor Timer Control](https://github.com/youssf123654/Continuous-Motor-Timer-Control)**
   * محاكاة لدائرة تشغيل وإيقاف محرك بشكل مستمر (5 ثواني عمل / ثانيتين إيقاف).

3. **[3-Alternating Motors Control](https://github.com/youssf123654/3-Alternating-Motors-Control)**
   * دائرة تحكم بالتبادل لتشغيل 3 محركات أو طلمبات لتوزيع الاحمال.

4. **[Three Motors Sequential Control](https://github.com/youssf123654/Three-Motors-Sequential-Control)**
   * دائرة التشغيل المتتابع لـ 3 محركات بفاصل زمني 5 ثواني باستخدام CADe_SIMU.

5. **[Two Conveyor Belt Control](https://github.com/youssf123654/two-conveyor-belt-control)**
   * محاكاة منطقية للتحكم المتتابع في سيرين ناقلين (Conveyor Belts).

6. **[3Phase Motor Forward Reverse CADe](https://github.com/youssf123654/3phase-motor-forward-reverse-cade)**
   * تصميم مخططات ومحاكاة لنظام عكس حركة محرك حثي 3 أجهاد باستخدام CADe_SIMU.

7. **[Three Phase Motor Start Stop Control](https://github.com/youssf123654/Three-Phase-Motor-Start-Stop-Control)**
   * تصميم CAD، ملفات محاكاة، وصور التنفيذ العملي لدائرة البدء والإيقاف لمحرك 3 أجهاد.

---
> 💡 **ملحوظة:** جميع المستودعات تحتوي على ملفات المحاكاة `.cad` جاهزة للتحميل والتجربة.
